# Тихая установка MSI

Тихая (silent) установка позволяет установить ПО без участия пользователя — без окон и нажатий.

## Базовая команда

```cmd
msiexec /i "package.msi" /qn /norestart
```

## Основные ключи

| Ключ | Действие |
|------|----------|
| `/i` | Установить пакет |
| `/qn` | Полностью тихий режим (без интерфейса) |
| `/qb` | Базовый интерфейс (прогресс-бар) |
| `/norestart` | Не перезагружать компьютер после установки |
| `/L*V "log.txt"` | Писать подробный лог установки |

## Примеры

Установка без окон:

```cmd
msiexec /i 7z.msi /qn /norestart
```

Установка с логом для отладки:

```cmd
msiexec /i package.msi /qn /L*V "C:\logs\install.log"
```

## Памятка

!!! tip "Совет"
    Перед массовой установкой проверьте команду на одном тестовом компьютере.
