# Такском: мастер настройки рабочего места

Инструкция по работе с «Мастером настройки рабочего места» (install.taxcom.ru).

## Открытие мастера

Два способа:

- по ссылке `install.taxcom.ru`;
- правая кнопка мыши по значку «Такском-Агент» в трее → «Настроить» → «Рабочее место».

Мастер проверяет настройку компьютера и браузера, при необходимости устанавливает корневые сертификаты.

## Типы проверки

- проверка компьютера;
- настройка браузера;
- проверка PDF-редактора.

## Результаты проверки

По итогам проверки появится одно из сообщений:

- **«Не смогли найти Такском-Агент»** — агент не установлен, установите его и повторите проверку;
- **«Настройка компьютера»** — мастер предложит выполнить необходимые действия;
- **любое другое сообщение** — следуйте подсказкам мастера.

После успешной настройки появится сообщение **«И компьютер настроен»**.

## Регистрация сертификата

После настройки зарегистрируйте сертификат в личном кабинете «Такском»:

- для представления отчётности;
- для электронного документооборота (ЭДО);
- для ЕПГУ (госуслуги).
