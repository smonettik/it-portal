# Развёртывание ПО

В компании применяется три способа установки программного обеспечения: централизованно через SCCM, через групповые политики и локальная тихая установка MSI на один компьютер.

## Выбор способа

- **SCCM** — массовая установка на коллекции устройств с отслеживанием статуса; подходит для регулярных обновлений;
- **GPO** — установка MSI-пакета на все компьютеры подразделения; проще, но без детального мониторинга;
- **Локальная MSI-установка** — разовая установка на конкретный компьютер, см. [Тихая установка MSI](msi-install.md).

## Развёртывание через SCCM

Требуется установленный клиент SCCM — см. [Агент SCCM](sccm-agent.md).

1. Открой консоль Configuration Manager.
2. Перейди в **Software Library** → **Application Management** → **Applications**.
3. **Create Application** → тип **Windows Installer (*.msi)** → укажи путь к пакету на сетевой папке.
4. На шаге **Programs** укажи команду установки, например:

    msiexec /i "package.msi" /qn

5. **Distribute Content** — раздай пакет на точки распространения (Distribution Points).
6. **Deploy** — выбери коллекцию устройств и расписание установки.
7. Контролируй установку: **Monitoring** → **Deployments**.

!!! tip "Готовые команды тихой установки"
    Ключи установки типовых пакетов собраны на странице [Тихая установка MSI](msi-install.md).

## Развёртывание через групповую политику

1. Положи MSI-пакет в сетевую папку, доступную всем компьютерам подразделения на чтение.
2. Открой `gpmc.msc`, создай GPO на нужном OU и открой **Edit**.
3. Перейди: Computer Configuration → Policies → Software Installation.
4. Правой кнопкой → **New → Package** → укажи путь к пакету **сетевым путём** (`\\server\share\package.msi`), не локальным.
5. Выбери **Assigned**.
6. Пакет установится на компьютеры при следующей перезагрузке.

## Устранение неполадок

1. **Пакет не устанавливается** — проверь доступ к сетевой папке с компьютера; журнал установки: Event Viewer → Windows Logs → Application.
2. **Компьютер не входит в коллекцию SCCM** — проверь агент клиента и границы (Boundaries), см. [Агент SCCM](sccm-agent.md).
3. **Политика Software Installation не видна** — помни, что установка происходит только при перезагрузке компьютера, а не при входе пользователя.

!!! warning "Важно"
    Не разворачивай непроверенный пакет сразу на всю компанию: сначала протестируй на тестовой коллекции из 5–10 компьютеров.
