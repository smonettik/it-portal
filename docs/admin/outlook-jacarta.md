# Шифрование почты в Outlook (JaCarta)

JaCarta — семейство российских средств криптографической защиты информации (USB-токены и смарт-карты). Для шифрования и цифровой подписи почты в Outlook с JaCarta необходимо выполнить ряд настроек.

## Предварительные требования

- **Оборудование:** токен JaCarta (например, JaCarta PKI, JaCarta ГОСТ);
- **Драйверы токена:** установите с официального сайта или с диска из комплекта;
- **Криптопровайдер:** КриптоПро CSP (с поддержкой ГОСТ) или совместимый;
- **Плагин для Outlook:** КриптоПро Office Signature или аналогичный;
- **Сертификаты:** действующий сертификат шифрования и подписи.

## Установка драйверов и ПО

1. Вставьте токен JaCarta в USB-порт.
2. Установите драйверы токена (обычно запускается автоматически или через `Setup.exe`).
3. Установите криптопровайдер КриптоПро CSP.
4. Установите плагин для Outlook (КриптоПро Office Signature).

## Настройка КриптоПро CSP

1. Откройте КриптоПро CSP (Пуск → КриптоПро → КриптоПро CSP).
2. Перейдите на вкладку «Оборудование» и нажмите «Настроить считыватели».
3. Добавьте считыватель JaCarta (обычно «Все смарт-карты и USB-токены»).
4. На вкладке «Общие» убедитесь, что выбран криптопровайдер «КриптоПро».

### Проверка подключения токена

1. В КриптоПро CSP перейдите на вкладку «Сервис».
2. Нажмите «Просмотреть сертификаты в контейнере».
3. Выберите считыватель с токеном JaCarta — при правильном подключении появится список контейнеров с сертификатами.

## Получение и установка сертификатов

### Генерация запроса на сертификат

1. В КриптоПро CSP перейдите на вкладку «Сервис».
2. Нажмите «Создать запрос на сертификат».
3. Заполните поля (ФИО, организация, e-mail и т.д.).
4. Выберите контейнер закрытого ключа на токене JaCarta.
5. Сохраните запрос в файл (обычно `.req`).

### Получение сертификата из УЦ

1. Отправьте файл запроса в удостоверяющий центр (УЦ).
2. Получите файл сертификата (обычно `.cer` или `.crt`).

### Установка сертификата

1. В КриптоПро CSP перейдите на вкладку «Сервис».
2. Нажмите «Установить личный сертификат».
3. Выберите полученный файл сертификата.
4. Выберите контейнер закрытого ключа на токене.
5. Установите сертификат в хранилище «Личные».

## Настройка Outlook

1. Откройте Outlook: Файл → Параметры → Центр управления безопасностью → Параметры центра управления безопасностью → Безопасность электронной почты.
2. В разделе «Цифровая подпись (S/MIME)» установите флажки:
   - «Добавлять цифровую подпись к исходящим сообщениям» (опционально);
   - «Шифровать содержимое и вложения исходящих сообщений».
3. Нажмите «Параметры» для настройки по умолчанию.
4. Нажмите «Выбрать» рядом с «Сертификат подписи» и выберите сертификат с токена JaCarta.
5. Повторите для «Сертификат шифрования» (обычно тот же сертификат).

!!! info "Дополнительно"
    При необходимости включите «Запрашивать подтверждение о получении S/MIME для каждого сообщения». В разделе «Расширенное сообщение» настройте отображение подписанных и зашифрованных сообщений.

## Использование шифрования

1. Создайте новое письмо в Outlook.
2. На вкладке «Параметры» нажмите «Шифровать» (иконка с замком).
3. Для подписи нажмите «Подписать» (иконка с лентой).
4. Отправьте письмо как обычно.

### Проверка зашифрованного письма

- При получении зашифрованного письма Outlook автоматически расшифрует его при наличии соответствующего сертификата на токене.
- Подписанные письма отображаются с иконкой ленты.

## Устранение неполадок

1. **Outlook не видит сертификат** — убедитесь, что токен подключён, драйверы установлены, сертификат установлен в хранилище «Личные».
2. **Ошибки шифрования/расшифровки** — проверьте, что у получателя есть ваш сертификат, что срок действия сертификата не истёк и используется правильный криптопровайдер.
3. **Токен не определяется** — переподключите токен в другой USB-порт, переустановите драйверы, проверьте видимость токена в КриптоПро CSP.

!!! warning "Важно"
    Для расшифровки ваших писем у получателей должен быть установлен ваш сертификат. Шифрование работает только между пользователями, обменявшимися сертификатами. Храните токен JaCarta и PIN-код в безопасности, обновляйте сертификаты до истечения срока действия.
