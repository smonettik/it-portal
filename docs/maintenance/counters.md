# Снятие показаний счётчиков

Система мониторинга периодически опрашивает устройства по SNMP и сохраняет срезы в файлы `counters_XX.csv`.

## Структура файла среза

| Столбец | Описание |
|---------|----------|
| Организация | Подразделение |
| IP-адрес | Адрес устройства в сети |
| Серийный № | Серийный номер устройства |
| ЧБ A4 / Цвет A4 / ЧБ A3 / Цвет A3 | Пробег по типам печати |
| Всего | Суммарный пробег |
| Тонер K/C/M/Y | Остаток тонера в % или WARNING |
| Барабан K/C/M/Y | Состояние барабана (% или OK) |
| Fuser Kit / Transfer Kit / Waste Toner | Состояние узлов |

## Как читать статусы

- **Число (0–100)** — остаток ресурса в процентах.
- **OK** — узел в норме.
- **WARNING** — ресурс на исходе, требуется замена.

## Примеры устройств, требующих внимания

| Устройство | Проблема |
|------------|----------|
| Kyocera ECOSYS M3040dn (S/N VCF394952) | Тонер K — WARNING |
| HP LaserJet P2055 (S/N VCF675168) | Тонер K — WARNING |
| Kyocera FS-C8520MFP (S/N E41414F153619) | Тонеры C, M, Y — WARNING |
| Xerox WorkCentre 3550 (S/N VCF485480) | Тонер K — 2 % |

!!! tip "Правило"
    Устройства со статусом WARNING попадают в план замены расходных материалов на текущую неделю.
