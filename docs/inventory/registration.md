# Регистрация устройства



При постановке нового принтера или МФУ на учёт его данные вносятся в реестр оборудования.



## Обязательные поля карточки



- **Организация** — ООО «Энергия-5»

- **Город** — Ангарск

- **Адрес** — Промзона, промзона АНХК, ТЭЦ-10, АБК

- **Кабинет** — 545

- **Производитель** — Xerox

- **Модель** — Xerox WorkCentre 3550

- **Серийный номер** — E63594G538014

- **IP-адрес** — 10.39.253.41



## Порядок действий



1. Списать данные с шильдика на корпусе устройства.

2. Подключить устройство к сети и получить IP-адрес.

3. Заполнить карточку в системе мониторинга.

4. Проверить доступность устройства командой ping.

5. Убедиться, что устройство появилось в файле счётчиков.



!!! warning "Важно"

    &#x20;    Серийный номер указывается без ошибок — по нему устройство сопоставляется с данными мониторинга.
